# HPAY Agent Wallet physical Local Pilot transaction scope

Date: 2026-08-02

## Objective

Build and verify one fresh Android ARM64 Pilot APK, use one authorized physical
Android device as the rollback witness, pair one restricted local reference
agent, and execute at most one small HAC transaction on HPAY Local Pilot Chain
V1. The run stops on any identity, balance, device, biometric, witness or
signing mismatch.

This is not mainnet, a public Hacash testnet, release validation or publication.

## Allowed Android pilot files

- `apps/mobile/src/agent/**`
- `apps/mobile/src/screens/AgentWalletScreen.tsx`
- `apps/mobile/src/api.ts`, only for the existing typed Agent companion surface
- `apps/mobile/src-tauri/src/**`, only for reviewed Agent companion IPC and
  Android Keystore or biometric bindings
- `apps/mobile/src-tauri/gen/android/**`, only when generated by the normal
  Tauri Android build and only after a scoped diff review

No Android source change is planned unless a physical-pilot blocker is proven.

## Allowed desktop companion files

- `apps/desktop/src/agent/**`
- `apps/desktop/src/screens/AgentWalletScreen.tsx`
- `apps/desktop/src-tauri/src/**`, only for the existing Agent companion and
  physical-pilot command surface

No Personal Wallet behavior or generic wallet command may be changed.

## Forbidden paths and actions

- Personal Wallet vault, settings, history, signing and transaction behavior
- `crates/wallet-core/**`, except read-only inspection
- Fast Pay L2, Dust Whisper, Harbor, pool and unrelated fullnode/miner code
- Hacash consensus, difficulty, Block 1, chain ID or network instance changes
- Agent vault reset, replacement or address change
- mainnet, HIP-20 Agent send, Agent L2, autonomous or automatic approval paths
- node API exposure beyond loopback or broad/public firewall rules
- Android uninstall, app-data clear, signer/package/version change
- whole-workspace formatting, mass dependency updates or destructive Git commands
- staging, commit, push, tag, release, APK publication or diagnostic upload

## Stop conditions

Stop before signing when any of the following is missing or mismatched: exact
Local Pilot identity, synchronized spendable/UI balance, authorized physical
ARM64 device, compatible installed signer, physical Keystore identity, real
biometric approval, same-LAN authenticated witness baseline, controlled
recipient, restricted agent session, zero Agent wallet fee, exact integer
amounts, total debit at or below 0.1 HAC, or clean unsigned negative-test state.
